# Evaluation evidence (copies)

Byte-for-byte copies of four documents from the private development archive, kept so the evaluation can be understood. They
are not edited. They refer to files that are not included here (frozen corpus, scoring forms, runner), so their hashes cannot be
verified in this repository.

- `FREEZE_MANIFEST.json`, `FREEZE_REPORT.md`: what was frozen, and the pre-run readiness report.
- `RUN_AUTHORIZATION.md`: the authorization. Its first lines say "UNSIGNED AND INACTIVE" because they were written before the owner
  activated it; the activation line at the bottom reads YES and carries the typed record dated 2026-11-20.
- `REQUIREMENTS_SUMMARY.md`: the 43 scoring requirements (15 Critical, 28 Major).

The final evaluation did **not** meet its acceptance criteria: see `../FINAL_EVALUATION_SUMMARY.md`.
